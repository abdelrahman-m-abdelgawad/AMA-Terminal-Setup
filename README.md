# AMA-Terminal-Setup

A portable Linux terminal setup for AMA Robotics.

This repository collects the current terminal identity and lets you move it between machines.
It is organized like a small distribution:

- `configs/` — terminal config files
- `scripts/` — helper scripts
- `tests/` — reproducible prompt and Git-state labs
- `assets/` — branding and welcome assets
- `versions/` — version snapshots and release notes

## Quick start

```bash
./install.sh
```

## Notes

Some branding assets are user-specific. The repo includes placeholders and scripts so the structure stays portable.
